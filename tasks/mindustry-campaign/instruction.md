# Mindustry — survive and achieve

Survive and earn as many achievements as possible, as efficiently as possible.
Start with this fresh normal campaign profile. Build, research, defend and progress
using normal game mechanics. This is not a race to an early campaign ending.

Progress is the fraction of the eligible achievements earned. More achievements
rank before faster play; at equal progress, earlier active-gameplay milestone
times rank better. Full completion means every eligible achievement. The native
collector records first-earned times; time spent thinking or paused is not scored.
Ordinary unit death and normal respawn are allowed, including when required by an
achievement. Survive normal gameplay; no separate permadeath rule is imposed.

Use screenshot to observe and act to send mouse/keyboard controls. An act call
already returns a fresh image and its observation ID: you do not need a separate
screenshot after every action. Cite the latest observation ID when acting.
Ordinary pausing is allowed; the harness does not automatically pause the game.

There is no total thinking-time, gameplay-time, token or action budget imposed by
this benchmark. You may plan and use the isolated local scratch shell. Provider
context/subscription limits and physical machine limits still exist. Confirmed
subscription exhaustion retains valid partial progress under available-subscription-v1;
other provider failures remain infrastructure, not native gameplay defeat.
Starting quota and shared-account usage may differ: this is an observational
available-subscription comparison, not a matched-quota measurement. Do not finish merely
because a benchmark budget is assumed. finish_attempt is permanent: use it only
to stop/give up; an early finish retains partial progress but is not completion.

Play as an ordinary player. Do not inspect hidden game state, game files or memory,
alter mechanics, grant resources/achievements, run console commands or import
external saves, blueprints, mods or internet content. Native in-attempt map,
schematic and logic creation are allowed. The native console can be opened for
its achievement but evaluation is disabled. A controlled language restart keeps
the same live profile and accumulated native time; it cannot revive a stopped run.
